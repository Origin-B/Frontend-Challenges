# Single Price Grid Component

![Desktop Design](./design/desktop-design.png)

## Overview

A responsive Single Price Grid Component built with pure HTML and CSS. This is a solution to the [Single Price Grid Component challenge](https://www.frontendmentor.io/challenges/single-price-grid-component-5ce41129d0ff452fec5abbbc) on Frontend Mentor.

## The Challenge

Users should be able to:

- View the optimal layout for the interface depending on their device's screen size
- See hover and focus states for all interactive elements on the page

## Built With

- Semantic HTML5
- CSS Custom Properties (Variables)
- Flexbox
- CSS Grid
- Google Fonts — [Karla](https://fonts.google.com/specimen/Karla)
- Mobile-first workflow

## Features

- ✅ Fully responsive (Mobile & Desktop)
- ✅ CSS Grid for desktop two-column layout
- ✅ Creative hover animation on the Sign Up button
- ✅ CSS Variables for consistent theming
- ✅ Clean box shadow for card depth
